# extreme-proofs-with-llm

Sampling Conway and Shipman's *extreme proofs* with a language model:
generate proofs of one theorem under prompts that each maximise one
attribute, embed them, and see where they land relative to a labelled
reference set of known proofs.

Write-up: **[Not all extremal directions are the same kind of
thing](https://jonathankeogh.com/writing/...)**

## The question

Conway and Shipman (*Extreme Proofs I: The Irrationality of √2*, Math.
Intelligencer 35(3), 2013) treat proofs as points in a space whose
coordinates are attributes — brevity, elementarity, generality, visuality,
weight of machinery — with *extreme proofs* as the vertices. They built
their space by hand from proofs in the literature. This asks whether a
language model can be used to sample it.

Short answer: the attributes are not coordinates of one space. Three select
among known arguments, one leaves the known set entirely, and one only
re-renders an argument you already had. See the write-up.

## The corpus

`proofs.jsonl` — 450 proofs of the infinitude of primes, generated by
`claude-opus-5` (medium effort, pinned snapshot, one model throughout) via
the Message Batches API. Two arms:

| arm | n | grid |
|---|---|---|
| technique | 300 | 5 techniques × 6 languages × 2 styles × 5 samples |
| extreme | 150 | 5 extremal criteria × 6 languages × 5 samples |

Technique arm techniques: Euclid, Euler product, Fürstenberg, Erdős
counting, Fermat numbers. Extreme arm criteria: brevity, elementarity,
generality, visuality, machinery.

Languages: en, fr, de, es, zh, ja. Chinese and Japanese are deliberate — a
European-only grid lets shared Latin roots give a multilingual embedding an
easy ride.

Each record stores its full prompt, model, effort, token cap and usage, so
the generation is auditable from the file. Treat `proofs.jsonl` as
immutable; version it rather than mutating it.

**One corpus intervention, disclosed.** The first run capped output at
10,000 tokens and produced 28 truncations, 83% of them in `generality`. The
cause was a prompt clause asking the model to "make that extension visible"
— a deliverable beyond the proof. Diagnosed from the prompt text before
reading any output, clause removed, cap raised, those 30 records
regenerated. Details in the write-up.

## Layout

```
generate.py          batch generation, resume-by-diff against proofs.jsonl
pilot/embed.py       embed with bge-m3, cache to embeddings.npy, first-pass probes
pilot/probes.py      structural probes: spectra, angles + nulls, centroids,
                     hard probes, lexical baseline
pilot/extreme.py     stage 3: classify the extreme arm against technique centroids
proofs.jsonl         the corpus
embeddings.npy       cached embeddings (450 × 1024), regenerable
```

## Running it

```bash
uv sync

export ANTHROPIC_API_KEY=...
uv run generate.py          # only if regenerating the corpus; a few dollars
uv run pilot/embed.py       # downloads bge-m3 (~2GB), caches embeddings
uv run pilot/probes.py      # instrument validation, seconds
uv run pilot/extreme.py     # the extreme-arm analysis, seconds
```

`probes.py` and `extreme.py` read the cached embeddings and make no API
calls — rerun them freely. Everything runs on a laptop; no GPU needed.

## What's actually in the analysis

Ordered by what survived.

**Held.** Language is additive and removable — subtracting each language's
mean embedding takes the same-technique/cross-language cosine gap from
+0.012 (a tie) to +0.378, and drops a language probe from 1.000 to 0.013
while technique classification stays at 1.000. Identical under leave-one-out
means, so not an artefact of in-sample centring. This is a replication of
[Libovický et al. 2020](https://arxiv.org/abs/2004.05160), which I found
after the fact.

**Held.** The extreme-arm direction × technique mapping, identical in all
six languages (χ² = 365.5, Cramér's V = 0.781).

**Did not hold.** Near-orthogonal principal angles between the factor
subspaces (min 78.9°). A permuted-label null lands at 77.0° (p = 0.86) and a
random-subspace null at 83.0° — the angle measures the dimensionality, not
the design.

**Did not hold.** "Technique structure survives translation" as a claim
about argument structure. A within-English TF-IDF baseline (word bigrams,
style held out) hits 0.940 against the embedding's 0.980 — technique
identity is largely lexical.

**Did not hold.** "Four of five directions leave the reference set,"
inferred from an out-of-set cosine threshold. Reading twelve proofs showed
only `machinery` does; the rest are out-of-*register*, not out-of-set.

The nulls and baselines are the point. `angle_null` and `lexical_baseline`
in `probes.py` each take about ten seconds and each killed a headline.

## Caveats

One theorem, one generator, two embedding models that disagree on
cross-lingual transfer. Proof correctness is unverified beyond twelve
records read by hand. Everything here is a fact about one model's
organisation of proof-writing, not about proofs.
